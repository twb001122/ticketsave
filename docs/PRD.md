# TicketSave 产品需求文档

## 1. 产品概述

`TicketSave` 是一款为脱口秀演员、喜剧创作者和演出记录者打造的 iOS 原生个人演出档案应用。

用户可以把自己参与的演出保存成一张张数字票卡，并持续累积演员、厂牌、场地等结构化资料，形成长期可回看的演出档案馆。

## 2. 目标用户

### 核心用户

- 脱口秀演员
- 主持人
- 漫才 / 即兴 / 新喜剧创作者
- 想长期整理个人演出经历的演出从业者

### 次级用户

- 演出厂牌运营者
- 需要整理票根式演出素材的内容创作者

## 3. 核心问题

当前用户在记录演出时常见痛点：

- 演出记录散落在相册、聊天记录、备忘录里
- 没有统一格式沉淀每场演出信息
- 后续很难做统计、回看或归档
- 图片、阵容、场地等资料缺乏结构化管理

## 4. 产品目标

### MVP 目标

- 让用户快速录入一场演出
- 自动形成一张高质感演出卡片
- 在首页持续积累和回看演出档案
- 用结构化实体管理演员、厂牌、场地
- 提供本地备份与恢复，保证资料安全

### 中长期目标

- 搭建演出统计系统
- 建立成就体系
- 形成长期可维护的个人演出生涯档案

## 5. 核心功能范围

### 5.1 首页 Archive

- 查看演出卡片列表
- 查看统计摘要
- 按内容形式筛选
- 按厂牌筛选
- 进入单场演出详情
- 通过右上角加号新增演出

### 5.2 新增 / 编辑演出

支持录入：

- 封面图片
- 演出标题
- 日期时间
- 场地
- 厂牌
- 演员阵容
- 内容形式
- 我的角色
- 演出属性
- 备注

设计原则：

- 所有字段尽量允许为空
- 不强制用户一次填完全部资料
- 优先保证记录动作轻量可持续

### 5.3 演出详情

- 查看通栏 Hero 封面图
- 查看主信息卡
- 查看日期时间、剧场、城市地点三张关键卡片
- 查看更多资料
- 查看演员阵容
- 编辑备注
- 删除演出

### 5.4 设置中心

- 主题模式切换
- 实体管理入口
- 本地备份入口

### 5.5 实体管理

管理以下三类实体：

- 演员
- 厂牌
- 场地

支持：

- 新增
- 编辑
- 左滑编辑 / 删除
- 手动建立实体间关联

### 5.6 本地备份

- 导出 ZIP 备份
- 导入 ZIP 备份
- 导入前确认覆盖本地数据

## 6. 数据模型需求

### 演出主记录 ShowRecord

必须支持：

- 演出内容形式
- 我的角色
- 演出属性
- 厂牌关联
- 场地关联
- 多演员关联

### 实体模型

#### 演员 Performer

- 名称
- 艺名 / 备注
- 关联厂牌
- 关联场地

#### 厂牌 ProductionBrand

- 名称
- 所属城市
- 关联演员
- 关联场地

#### 场地 Venue

- 名称
- 城市
- 区县 / 商圈
- 地址
- 关联演员

## 7. MVP 明确不做

- 自动云同步
- 多端冲突合并
- 社交分享系统
- 外部账号体系
- 成就系统正式页
- 复杂图片编辑器

## 8. 成功标准

### 功能层

- 用户能在 1 分钟内录入一场演出
- 首页能稳定展示档案列表
- 删除与编辑行为一致可靠
- 本地备份与恢复可用

### 体验层

- 视觉风格统一
- 亮暗主题都舒适
- 列表滚动和详情打开足够顺滑
- 用户愿意长期把它当作自己的演出档案馆使用

## 9. 后续演进方向

- 年度 / 月度统计
- 演出次数和角色统计
- 厂牌合作频次
- 常演场地统计
- 成就体系
- 海报分享图导出
